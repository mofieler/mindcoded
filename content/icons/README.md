# Technik-Logos (Leiste »Werkzeuge & Technik«)

Quelle: [Simple Icons](https://simpleicons.org) 13.21.0 (npm `simple-icons`), Lizenz CC0-1.0.
Die Marken gehören ihren Inhabern; sie werden nur genannt, um eingesetzte Werkzeuge zu beschreiben.

Neues Logo: SVG aus dem Paket hierher kopieren und in `content/site.json › tools` eintragen.
Der Build übernimmt nur die Pfade (`<path d="…">`) und färbt sie in der Schriftfarbe der Seite.
